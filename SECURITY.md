# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for `mtibebu/specadia` when available. If private reporting is unavailable, contact the
repository owner through a private channel listed on their GitHub profile.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Remove
credentials, personal data, and proprietary design artifacts from reports. Maintainers will
acknowledge a report when received and coordinate disclosure after a fix is available.
